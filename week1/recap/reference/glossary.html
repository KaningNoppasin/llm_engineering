Week 1 glossary

The compressed vocabulary. Print it, pin it, reuse the terms exactly.

TermMeaningDay
Chat Completions APIThe endpoint that takes a conversation (list of messages) and predicts the next message. The core of Week 1.1–2
System promptMessage that sets the model's task, rules, and tone for the call.1
User promptMessage carrying the actual request or data for this call.1
Assistant messageThe model's reply; included in history to give later turns context.4
.envUntracked file holding secrets (OPENAI_API_KEY); read by load_dotenv().1
uvFast Rust-based Python package/venv manager used to set up the project.1
OllamaTool to download & run open-source models locally; exposes an OpenAI-compatible endpoint at localhost:11434/v1.1–2
base_urlThe endpoint the OpenAI client targets; change it to call Gemini, Ollama, etc.2
Frontier modelClosed, paid, top-capability model (GPT-5, Claude, Gemini, Grok).2–3
Open-weight modelModel whose trained weights are public (Llama, Mistral, Qwen, Gemma, DeepSeek); training data usually isn't.2
DistillationTraining a small model on synthetic data from a large one to compress capability cheaply.2
Base modelRaw next-token predictor, not instruction-tuned; a starting point for fine-tuning.3
Chat / instruct modelBase model tuned via RLHF to follow message-based instructions.3
Reasoning modelEmits a thinking trace before the answer; better on hard problems, slower/pricier.3
Hybrid modelDecides per query how much to reason (GPT-5, Gemini 2.5 Pro).3
RLHFReinforcement Learning from Human Feedback — turns a base model into a chat model.3
Budget forcingInjecting "wait" into a reasoning trace to make the model reason longer (S1 paper, 2025).3
HallucinationConfident, plausible-sounding but false output; models optimize plausibility, not truth.3
Knowledge cutoffThe training date past which the model knows nothing without external search.3
Agentic AIMany chained model calls doing autonomous multi-step work (Deep Research, Claude Code).3
Transformer2017 architecture ("Attention Is All You Need"); the T in GPT. Parallelizable.4
AttentionLayer that weighs which earlier tokens matter for predicting the next one.4
LSTMOlder sequential architecture transformers replaced; couldn't parallelize.4
ParametersLearnable weights. GPT-1 117M → GPT-3 175B → GPT-4 ~1.76T.4
TokenChunk of text (~4 chars / ~0.75 words). The unit you're billed in.4
tiktokenOpenAI's tokenizer library; encode/decode text ↔ token IDs.4
Context windowMax tokens a model accepts as input (GPT-5 ~400k, Claude ~200k, Gemini ~1M).4
Illusion of memoryCalls are stateless; "memory" exists only because you resend the full history.4
Prompt chainingFeeding one call's output into the next, with logic between, to build a product.5
One-shot / multi-shotGiving one (or several) example(s) of the desired output in the prompt.5
response_format{"type":"json_object"} forces valid-JSON generation for reliable parsing.5
Streamingstream=True yields delta.content chunks token-by-token (SSE).5
