Transformers, tokens & the illusion of memory

What's actually under the hood — and why every chat is stateless.

Why this matters for the switch: the three ideas here — attention, tokens, statelessness — explain almost every practical question you'll hit later: context limits, API bills, why long chats get expensive, and why "memory" is something you engineer.

Today's win

You can explain why an LLM "remembers" nothing between calls, and count the tokens (and rough cost) of any prompt with tiktoken.

Architecture in three beats

  • Transformers (2017). The "T" in GPT, from Google's Attention Is All You Need. Their superpower is parallelism.1
  • Attention is the layer that decides which earlier tokens matter most when predicting the next one — letting the model weigh context instead of reading strictly left-to-right.
  • Why transformers beat LSTMs. LSTMs were arguably more powerful per step but sequential — each step waits on the last, so they can't parallelize. Transformers traded some theoretical depth for massive parallel training, which let them scale on far more data.
  • Emergent intelligence. Scale them up enough and predicting likely text starts producing accurate text — understanding that nobody fully explains.

The illusion of memory

Every API call is stateless. The model has no memory of your last message. A chat "remembers" only because you resend the entire conversation in the messages list every time. That's why long conversations cost more — the model must re-read all prior tokens to predict the next one.
