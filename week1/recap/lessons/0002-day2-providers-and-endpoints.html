One client, many providers

The endpoint under the hood, and why the same code calls OpenAI, Gemini & Ollama.

Why this matters for the switch: AI engineers are rarely locked to one vendor. Knowing that "the API" is just an HTTP endpoint — and that everyone copied OpenAI's shape — means you can swap models for cost, quality, or privacy with a one-line change. That flexibility is a hireable skill.

Today's win

You can point the same OpenAI Python client at OpenAI, Google Gemini, or a local Ollama model by changing only base_url and api_key.

The big realization

The "Chat Completions API" is just an HTTP endpoint that takes a conversation and returns the next message. The OpenAI Python client is a thin, open-source wrapper around that web request — it contains no model code. Because Google, Anthropic, and Ollama all expose OpenAI-compatible endpoints, the same client library talks to all of them.

Key concepts

  • Chat Completions = predictive text. You hand the model the conversation so far; it predicts the most likely next message (the next tokens). That's the whole game.
  • Frontier vs open. Frontier models (GPT-5, Claude, Gemini, Grok) are closed and paid. Open models (Llama, Mistral, Qwen, Gemma, DeepSeek) ship their weights — though the training data usually isn't public, so "open-weight" is the precise term.
  • The client is just HTTP. The OpenAI library wraps a POST to /v1/chat/completions. You could send the raw request yourself with requests.
  • OpenAI-compatible endpoints. Swap base_url + api_key and the identical code hits Gemini or a local Ollama server.
  • Three ways to use a model. A packaged product (ChatGPT), a cloud API call, or local inference (Ollama / Hugging Face).
  • Distillation is how small models get smart cheaply: a big model generates synthetic training data to "teach" a small one. DeepSeek R1 was trained for roughly $4M using such efficiency tricks.

The same call, three providers

from openai import OpenAI

# OpenAI (default base_url)
client = OpenAI()

# Google Gemini — same client, different endpoint + key
gemini = OpenAI(
    base_url="https://generativelanguage.googleapis.com/v1beta/openai/",
    api_key=GOOGLE_API_KEY,
)

# Local Ollama — runs on your machine, api_key is a placeholder
ollama = OpenAI(base_url="http://localhost:11434/v1", api_key="ollama")

# identical call shape for all three:
gemini.chat.completions.create(model="gemini-2.5-pro", messages=messages)

And the raw HTTP the client hides from you — useful to have seen once:

headers = {"Authorization": f"Bearer {api_key}", "Content-Type": "application/json"}
payload = {"model": "gpt-5-nano", "messages": messages}
requests.post("https://api.openai.com/v1/chat/completions", headers=headers, json=payload)
