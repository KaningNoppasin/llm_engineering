Results & cross-entropy

The payoff: a fine-tuned 3B open model beats the frontier — and why.

Why this matters for the switch: this is the capstone result you can put on a résumé: a 3B model you fine-tuned beating GPT-5.1 on a real task. Understanding why — and cross-entropy, how LLMs actually learn — is exactly what an interviewer wants to hear.

Today's win

You can run inference on a QLoRA model (base + adapters), turn its token probabilities into a sharp price, and explain cross-entropy loss.

Key concepts

  • Inference = base + adapters. Load the 4-bit base, then overlay the trained LoRA adapters from the Hub with PeftModel.from_pretrained(...) (and a revision for the best checkpoint).
  • Sharpen the prediction with top-k. Don't take the single most-likely token — read the top-k token probabilities and compute a probability-weighted average for a smoother, more accurate price.
  • The forward pass outputs a distribution. The LM head produces 128,256 logits; softmax turns them into probabilities that sum to 1.
  • Cross-entropy loss = −log(ptrue). The loss is the negative log of the probability the model gave the correct next token. Predict it with certainty → loss 0; low probability → high loss.
  • Backprop trains only the adapters. Gradients flow back via the chain rule, but the frozen 4-bit base gets none — only the LoRA matrices update.
  • Small + specialized beats big + general. The 3B model (runs on a phone) wins because it has task-specific expertise from your data; frontier models are generalists that never saw it.
  • This is the whole course in one result. Curate data (W6) → quantize + LoRA (W7) → train → evaluate → beat the baseline. That's the job.

The code shape to memorize

from peft import PeftModel

# base (4-bit) + trained adapters from the Hub
base  = AutoModelForCausalLM.from_pretrained(BASE, quantization_config=bnb, device_map="auto")
model = PeftModel.from_pretrained(base, ADAPTERS, revision=best_commit)

# weighted-average over the top-k next-token probabilities -> sharper price
logits = model(**inputs).logits[0, -1]          # distribution over next token
probs  = logits.softmax(dim=-1)
top = probs.topk(5)
price = sum(p * int(tokenizer.decode(t)) for p, t in zip(top.values, top.indices))
Interview-ready framing: "How can a 3B model beat GPT-5.1?" — Specialization. Frontier models spent ~$100M on broad ability; your fine-tune spent capacity entirely on this domain with 800K examples. For a narrow, data-rich task, focused beats vast.
