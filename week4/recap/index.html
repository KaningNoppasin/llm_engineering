Week 4 — choosing & evaluating models

Five daily recaps with active-recall quizzes. The week you learn to pick the right model.

The week in one line: a model-selection workflow + benchmarks (Day 1) → the leaderboards that answer each question (Day 2) → frontier models porting Python→C++ (Day 3) → open-source code models in a compare UI (Day 4) → technical vs business evaluation + the Rust challenge (Day 5).

The five lessons

  • Day 1 — Choosing a model & reading benchmarks. Two-phase selection, Chinchilla, GPQA/MMLU-Pro/HLE, contamination.
  • Day 2 — Leaderboards & commercial patterns. Artificial Analysis, SEAL, LiveBench, LM Arena; automation→augmentation→agentic.
  • Day 3 — Python → C++ with frontier models. Translation prompt, native compile, model speedups.
  • Day 4 — Open-source code models & a compare UI. Model dispatch, Gradio dropdown, open beats frontier.
  • Day 5 — Evaluation & the Rust challenge. Technical vs business metrics, perplexity, Kadane's, 111,000×.
