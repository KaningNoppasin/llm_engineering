LLM Engineering ● Week 2 ● Day 5 Recap

Multimodal & agentic assistants

Images, speech, and custom layouts — the whole week stitched into one app.

Why this matters for the switch: the capstone — you combine tools, image generation, and audio into a single assistant with a custom UI. This is exactly the kind of end-to-end build that becomes a portfolio centerpiece and an interview talking point.

Today's win

You can generate an image with DALL·E 3 and speech with TTS, and lay out a multi-component app with gr.Blocks — then explain what makes it "agentic."

Three new capabilities

  • Image generation (DALL·E 3). openai.images.generate(...) with response_format="b64_json" returns a base64 image you decode in Python — no file I/O. Note: images are pricey (~$0.04 each) vs. text calls.
  • Text-to-speech. openai.audio.speech.create(model="gpt-4o-mini-tts", voice="onyx", …) returns audio bytes you can play back (voices include onyx, alloy, coral).
  • gr.Blocks for custom layouts. Where gr.Interface is one function in/out and gr.ChatInterface is a prebuilt chat, Blocks lets you place components in Row/Column containers and wire events with .submit(...).then(...).
  • Agentic AI = a task broken into multiple coordinated LLM/tool calls with some autonomy. Hallmarks: breaking work into steps, using tools, persistence/memory, planning, and the model itself deciding the next action.
  • It all composes: the airline assistant calls a price tool, then generates a city image, then speaks the reply — multiple modalities triggered from one conversation.
  • OpenRouter (extra) lets you compare frontier and open models behind one key — handy for picking the right model per task (a Week 4 theme previewed).

The code shapes to memorize

# DALL-E 3 image -> base64 (decode and show, no file needed)
img = openai.images.generate(model="dall-e-3",
                            prompt=f"Pop-art image of {city}",
                            size="1024x1024", response_format="b64_json")
b64 = img.data[0].b64_json

# text-to-speech -> audio bytes
audio = openai.audio.speech.create(model="gpt-4o-mini-tts",
                                    voice="onyx", input=text).content

# gr.Blocks: custom layout + event wiring
with gr.Blocks() as ui:
    with gr.Row():
        chatbot = gr.Chatbot(height=500)
        image   = gr.Image(height=500)
    entry = gr.Textbox()
    entry.submit(add_message, [entry, chatbot], [entry, chatbot]) \
         .then(chat, chatbot, [chatbot, image])   # chain events
ui.launch()
Interview-ready framing: "What makes something an agent vs a chatbot?" — A chatbot answers one turn; an agent decomposes a goal into steps, calls tools, and decides the next action itself. Today's assistant is the first real agent you've built — tools (Day 4) + modalities + a loop that lets the model drive.
