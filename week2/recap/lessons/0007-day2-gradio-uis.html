UIs without front-end skills

Gradio: wrap a Python function in a web UI, and stream into it.

Why this matters for the switch: a backend engineer who can put a shareable UI in front of an LLM in 5 lines ships demos that get noticed. Gradio is how you turn a notebook into something a hiring manager (or stakeholder) can click.

Today's win

You can wrap any function in gr.Interface(...).launch() and make its output stream by turning the function into a generator.

What Gradio is

Gradio is an open-source Python library (owned by Hugging Face) that builds a web UI from a Python function — no JavaScript, no HTML. You hand it a callback and the input/output component types; it spins up a local web server and a React front end.

Key concepts

  • gr.Interface(fn, inputs, outputs) is the core: a function plus the shapes of its inputs and outputs. .launch() serves it on a local port (~7860).
  • You pass the function by reference (fn=shout, not shout()) so Gradio decides when to call it with the user's input.
  • Components describe the I/O: gr.Textbox(label=…, lines=N) in, gr.Markdown() out to render bold/bullets from an LLM nicely.
  • share=True publishes a public tunnelled URL (valid ~1 week) that calls back to your machine — great for demos, but it can trip corporate firewalls.
  • Auth & convenience. auth=("user","pass") adds a login screen; inbrowser=True auto-opens the tab.
  • Streaming is automatic for generators. If your callback yields, Gradio detects it and progressively refreshes the output as chunks arrive.

The code shapes to memorize

import gradio as gr

# minimal interface
def shout(text):
    return text.upper()

gr.Interface(fn=shout, inputs="textbox", outputs="textbox").launch()

# streaming: make the callback a GENERATOR and yield cumulative text
def stream_gpt(prompt):
    stream = openai.chat.completions.create(model="gpt-4.1-mini",
                                              messages=[...], stream=True)
    result = ""
    for chunk in stream:
        result += chunk.choices[0].delta.content or ""
        yield result     # Gradio refreshes the display each yield

gr.Interface(fn=stream_gpt, inputs="textbox", outputs=gr.Markdown()).launch()
Gotcha: for streaming you must yield the accumulated string, not each new fragment — Gradio replaces the output with whatever you yield, so yield the growing result. And pass fn=stream_gpt (reference), never fn=stream_gpt().
