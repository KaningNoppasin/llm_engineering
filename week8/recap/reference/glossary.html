Week 8 glossary

New terms from Week 8. See also the Week 1, 2, 3, 4, 5, 6, and 7 glossaries.

TermMeaningDay
Agentic AIAn LLM controlling a workflow with agency — choosing tools in a loop until a goal is met.1, 4
ModalServerless platform; define container/GPU/secrets in Python, pay per compute used.1
Ephemeral vs deployedmodal run ships code each time (slow); modal deploy builds once (fast).1
Modal secretSecurely stored API key injected as an env var into a remote function.1
Modal volumePersistent disk caching model weights across invocations to cut cold starts.1
Cold startFirst-call latency to spin up a container and load weights (mitigated by deploy + volume).1
.remote()Calls a deployed Modal function/class method in the cloud and returns the result.1
Specialist agentThe fine-tuned Llama pricer (Week 7) deployed on Modal.1, 2
RAG pricer (frontier)Retrieves similar priced items as context for a frontier model to estimate price.2
EnsembleBlending multiple diverse models; uncorrelated errors cancel for a better result.2
Structured outputsForcing the model to return data matching a Pydantic schema.3
Constrained decodingZeroing out tokens that would break the schema, so only valid JSON is emitted.3
Pydantic BaseModelA class defining a schema; used as response_format for structured outputs.3
parse()chat.completions.parse(response_format=Model) returns a typed .parsed object.3
Deal scannerAgent that reads RSS feeds and extracts structured deals (description, price, url).3
PushoverService for sending push notifications to your phone via a simple POST.3
Planning agentAn agent that orchestrates other agents (as tools) to accomplish a goal.4
Agent loopwhile not done: call model with tools, run any tool calls, repeat until plain text.4
Tool orchestrationExposing each agent's method as a tool so a planner can call them autonomously.4
DealAgentFrameworkOrchestrator wiring agents + Chroma + logging + persistent memory + the run cycle.4, 5
Memory (memory.json)Persisted Opportunity objects fed back into prompts so the agent avoids repeats.4, 5
gr.TimerGradio component that ticks on an interval to run the workflow autonomously.5
Observability / logging queueStreaming per-agent logs into the UI to watch the system run live.5
