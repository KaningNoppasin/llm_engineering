Today's win

The full stack, in one diagram

The final app ties together everything from eight weeks: a fine-tuned model on Modal + RAG + ensemble pricing, a scanner using structured outputs, a planning agent orchestrating it all, persistent memory, push notifications, and a live Gradio UI — running autonomously.

Key concepts

  • Autonomous scheduling. gr.Timer(value=300, active=True) ticks every 5 minutes and runs the entire agent workflow with no human input — the system drives itself.
  • The deals table. A gr.Dataframe shows each opportunity: description, deal price, estimated value, discount, and URL.
  • Live observability. A logging queue streams colored per-agent logs into the UI so you can watch the agents work in real time; a 3D Plotly scatter visualizes the Chroma vectors.
  • Memory prevents repeats. Past Opportunity objects are loaded from JSON and passed into prompts, so the platform never re-recommends a deal it already found.
  • Three definitions of "agentic". Works independently (Altman); the LLM controls the workflow (2025 consensus); an LLM in a loop with tools achieving a goal — your system.
  • The 8-week skill stack. tokens & APIs → providers & UIs → open models → model selection & eval → RAG → data & fine-tuning → QLoRA → agents & deployment. You've now done all of it.
