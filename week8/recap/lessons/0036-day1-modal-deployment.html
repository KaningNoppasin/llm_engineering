Serverless deployment on Modal

Put your fine-tuned model in the cloud and call it as a remote service.

Why this matters for the switch: a model that only runs in your notebook isn't a product. Deploying it serverlessly — GPU on demand, pay-per-use, callable from anywhere — is the step that makes you an AI engineer, not just a notebook tinkerer.

Today's win

You can deploy the fine-tuned Llama pricer to Modal with a GPU and persistent storage, and call it remotely with .remote() — the first agent in the platform.

What Modal gives you

Modal is a serverless platform: you describe the container (image, GPU, secrets) in Python with decorators, and Modal runs it in the cloud, billing only for compute used. No servers to manage, GPUs on demand.

Key concepts

  • Agentic AI, defined. An LLM that controls a workflow with agency — deciding steps, calling tools in a loop until a goal is met. An "agent" can start as simply as Python wrapping a model call.
  • Infrastructure as code. @app.function(image=…, gpu="T4", secrets=…) declares the environment; Modal builds and runs it.
  • Ephemeral vs deployed. modal run ships your code each time (slow cold start ~1m20s); modal deploy builds once so later calls stay fast (~30s cold, ~2s warm).
  • Secrets keep API keys (e.g. your HF token) out of code — stored in Modal, injected as env vars into the remote function.
  • Volumes = persistent disk. Cache the multi-GB model weights on a Modal volume so you don't re-download them every cold start.
  • Call it remotely. modal.Cls.from_name("pricer-service", "Pricer")() gets a handle; .price.remote(description) runs it in the cloud and returns the result.
  • Preprocess to match training. Format inference input exactly like the training prompts so the fine-tuned model behaves consistently.

The code shape to memorize

import modal
app = modal.App("pricer-service")
image = modal.Image.debian_slim().pip_install("torch", "transformers", "peft")
secrets = [modal.Secret.from_name("huggingface-secret")]

@app.cls(image=image, secrets=secrets, gpu="T4", timeout=1800)
class Pricer:
    @modal.method()
    def price(self, description: str) -> float:
        # load 4-bit base + LoRA adapters, generate, parse the number
        return price

# deploy once, then call from anywhere:
#   modal deploy -m pricer_service
pricer = modal.Cls.from_name("pricer-service", "Pricer")()
pricer.price.remote("Used iPhone 14, 128GB, good condition")
Interview-ready framing: "What's a cold start and how do you fight it?" — The first call after idle must spin up a container and load weights (~1m+). deploy (build once) + a volume (cache weights) cut it to ~30s; keeping it warm cuts it to ~2s.
