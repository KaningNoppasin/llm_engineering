Curating a training dataset

The capstone begins: predict a product's price from its description.

Why this matters for the switch: the unglamorous truth of AI jobs is that data work drives results more than model choice. Curating a clean, balanced, leak-free dataset is a core, hireable skill — and it's where this week's capstone lives or dies.

Today's win

You can take a messy public dataset, filter and balance it, split it leak-free, and push the curated result to the Hugging Face hub.

The capstone: "The Price is Right"

The goal for Weeks 6–8 is a regression task: predict a product's price from its text description, using Amazon product data. Today is all about building the dataset that everything else will be measured against.

Key concepts

  • Generalization is the whole game. A model is good only if it predicts well on unseen data — learning patterns, not memorizing examples.
  • Fine-tuning ≠ pretraining. You take a pre-trained model and train it further on your data (transfer learning) — vastly cheaper than the millions it costs to train from scratch.
  • Data quality > hyperparameter tuning. Curating the dataset usually moves the needle more than fiddling with the model. Spend the effort here.
  • Filter ruthlessly. Keep items with a real price, descriptions ~600–4,000 chars, prices in a sane range ($0.50–$999.49). Junk in = junk predictions.
  • Fix distribution skew. The data skews cheap (and toward Automotive). Weighted sampling (e.g. weight by price, down-weight overrepresented categories) rebalances it so the model sees the full range.
  • Remove duplicates to prevent leakage. The same item in train and test inflates your validation score and hides overfitting — data leakage is a classic, costly bug.
  • Three splits. Train (learn), validation (tune), test (held in reserve, touched last). Here: ~800k / 10k / 10k (full), or 20k / 1k / 1k (lite).

import numpy as np

# 1. load + filter
data = load_dataset("McAuley-Lab/Amazon-Reviews-2023", "raw_meta_Appliances", split="full")
items = [parse(d) for d in data if 0.5 <= price(d) <= 999.49]
