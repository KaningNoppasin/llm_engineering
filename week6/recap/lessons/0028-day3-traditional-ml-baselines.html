LLM Engineering ● Week 6 ● Day 3 Recap

Traditional ML baselines

From a random guess to XGBoost — always have a number to beat.

Why this matters for the switch: reaching for an LLM first is a junior move. The engineer who builds a cheap baseline — and sometimes ships it — saves money and earns trust. scikit-learn fluency is still expected in most ML interviews.

Today's win

You can turn product text into features with Bag-of-Words and train a ladder of baselines (linear → Random Forest → XGBoost), each measured by the same error metric.

Why baselines first

Before any fancy model, you build a baseline — even a random guess — so every later approach has a number to beat. The day climbs a ladder, each rung a real model, watching the mean absolute error (MAE) in dollars fall.

The ladder (MAE in $, lower is better)

ModelWhat it doesMAE
Random pricerGuesses 1–999, ignores the text$382
Constant pricerAlways guesses the average price ($140)$106
Linear regression (weak features)Weight + text length only$102
Bag-of-Words + Linear regression2,000 word-count features$77
Random Forest100 trees, averaged$72
XGBoostSequential trees correcting errors$68

Key concepts

  • The constant baseline is sneaky-good. Always guessing the average ($106 MAE) crushes random guessing ($382) — the task has a natural center of mass.
  • Features > algorithm. The big jump ($102 → $77) came from better features (word counts), not a fancier model.
  • Bag-of-Words / CountVectorizer turns text into numbers by counting the top ~2,000 words (dropping stop-words like "the"). Each product becomes a 2,000-number vector.
  • Random Forest = many decision trees on random data/feature subsets, averaged — robust, parallel.
  • XGBoost builds trees sequentially, each correcting the previous one's errors — usually faster and a bit better.
  • One evaluation harness. Every model is scored the same way (MAE, plus a ŷ-vs-y scatter and R²) so comparisons are fair.

The code shape to memorize

from sklearn.feature_extraction.text import CountVectorizer
from sklearn.linear_model import LinearRegression

# text -> 2000-word feature vectors
vec = CountVectorizer(max_features=2000, stop_words="english")
X = vec.fit_transform(documents)

# every sklearn model: create -> fit -> predict
model = LinearRegression()        # or RandomForestRegressor(), XGBRegressor()
model.fit(X, prices)
pred = model.predict(new_X)

evaluate(model, test_set)         # MAE + R^2, same harness for all
Interview-ready framing: "What's R²?" — 0 means no better than guessing the average, 1 is perfect, negative means worse than the average baseline. It tells you whether your model captures the trend, while MAE tells you how far off in dollars.
