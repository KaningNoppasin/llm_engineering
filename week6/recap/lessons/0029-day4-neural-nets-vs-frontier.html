Neural nets vs frontier models

Your first PyTorch net — and a humbling: zero-shot frontier LLMs beat it.

Why this matters for the switch: writing a PyTorch training loop and reading a model-vs-model leaderboard are both interview staples. The surprise — frontier LLMs beating a trained net with no task training — is exactly the kind of insight that shows real understanding.

Today's win

You can write a basic PyTorch neural net and its training loop, and benchmark it against frontier LLMs and a human baseline on the same task.

The training loop, in four moves

Every neural network trains the same way: forward pass → loss → backward pass → optimizer step, repeated over batches for several epochs. Today's net is 8 layers (~669k params) fed 5,000 Bag-of-Words features.

Key concepts

  • The four training steps. outputs = model(x) (forward) → loss = loss_fn(outputs, y) → loss.backward() (gradients) → optimizer.step() (update weights).
  • Hyperparameters set the run: batch size 64, learning rate 0.001, 2 epochs, MSE loss, Adam optimizer, 5,000-feature input.
  • A human baseline matters. Ed scored $87.62 on 100 items — proof the task is genuinely hard and a yardstick for "good."
  • Frontier models are tested zero-shot. No fine-tuning — just a prompt asking for the price, parsing the number from the reply.
  • The humbling result. Frontier LLMs (best: GPT-5.1, $44.74) beat the trained net ($63.97) using only pre-training knowledge — they've effectively "seen" product pricing.
  • Two metrics, fairly applied. MAE (dollars off) and R² (trend captured) via the same ŷ-vs-y harness used since Day 3.

The code shape to memorize

import torch.nn as nn

class Pricer(nn.Module):
    def __init__(self, n):
        super().__init__()
        self.net = nn.Sequential(nn.Linear(n, 128), nn.ReLU(),
                                 nn.Linear(128, 64), nn.ReLU(), nn.Linear(64, 1))
    def forward(self, x): return self.net(x)

# the training loop = the four moves
for epoch in range(EPOCHS):

        optimizer.zero_grad(); loss.backward()   # gradients
        optimizer.step()              # update weights
