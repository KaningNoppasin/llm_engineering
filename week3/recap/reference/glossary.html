Week 3 glossary

The open-source week: Hugging Face, pipelines, tokenizers, quantization. Print & pin.

New terms from Week 3. See also the Week 1 and Week 2 glossaries.

TermMeaningDay
Hugging Face HubPlatform hosting Models, Datasets, and Spaces — "GitHub for AI" (2M+ models).1
SpacesHF-hosted apps (often Gradio/Streamlit) you can deploy and share.1
transformersThe core HF library for loading and running transformer models.1, 4
datasets / hubHF libraries for data handling and for connecting to/downloading from the Hub.1
Google ColabHosted notebook running on Google's cloud machines with optional GPUs.1
T4 / A100GPUs in Colab: free T4 (15 GB VRAM), paid A100 (40 GB, ~$0.50/hr).1
HF_TOKENAccess token (hf_…); needs write scope to upload; stored in Colab Secrets.1
Gated modelA model (e.g. Llama) requiring license acceptance before download.1, 3
Diffusion modelImage generator (Stable Diffusion XL, FLUX); denoises over num_inference_steps.1
pipeline()High-level inference API: tokenize → run → post-process behind one call.2
TaskWhat a pipeline does: sentiment, ner, question-answering, summarization, etc.2
device="cuda"Run on the Nvidia GPU (mps = Apple Silicon, CPU default).2
AutoTokenizerfrom_pretrained(model) loads the right tokenizer for a model.3
encode / decodeConvert text → token IDs and back; IDs are model-specific.3
Special tokensReserved IDs (BOS, EOS, role markers) signalling structure, learned in training.3
apply_chat_templateFormats a message list into the model's expected token string with special tokens.3, 4, 5
add_generation_promptAppends the assistant header so the model knows it's its turn to speak.3
Vocab sizeNumber of tokens a model knows (Llama 3.1: 128,256); a size/efficiency tradeoff.3
AutoModelForCausalLMLow-level loader for autoregressive (next-token) models.4
Causal LMPredicts each token from prior tokens only (causal mask blocks the future).4
QuantizationStoring weights in fewer bits (4-bit nf4) to cut memory ~4× with little quality loss.4, 5
BitsAndBytesConfigConfig object enabling load_in_4bit, nf4, bfloat16 compute, double-quant.4
device_map="auto"Auto-places model weights across available GPU/CPU memory.4
Embedding layerMaps each vocab token ID to a dense vector (e.g. 2,048 dims).4
Decoder layerSelf-attention (Q/K/V/output) + MLP (up/gate/down) + layer norm; stacked N times.4
Non-linearityActivation (SiLU/ReLU) in the MLP; without it, stacked linear layers collapse to one.4
LM headFinal layer mapping the hidden state to vocab-sized logits for the next token.4
model.generate()Runs token-by-token generation given input token tensors.4, 5
WhisperOpenAI speech-to-text model; free via HF pipeline or paid via API.5
TemperatureRandomness of token choice: 0 = greedy/deterministic, higher = more varied.5
TextStreamerUtility that decodes and prints tokens as they are generated.5
